Tabsift

Fuzzy flikpalett, dubblettstädning och semantisk gruppering. AI är valfri — dubblettstädningen och paletten fungerar helt utan.

Behörigheter

Tillägget begär tabs, tabGroups, storage och commands. Inga content scripts, ingen <all_urls>, ingen historik, inga bokmärken, ingen telemetri. Nätverksanrop görs bara till den AI-endpoint du själv väljer nedan, och behörigheten för den frågas separat.

AI-backend

Ollama blockerar tillägg via CORS som standard. Starta servern med OLLAMA_ORIGINS='chrome-extension://…' för att tillåta det här tillägget.

Fungerar mot OpenAI, LM Studio, llama.cpp och OpenRouter. Lokala servrar behöver ingen nyckel. Egna domäner måste läggas till i optional_host_permissions i manifest.json.

Nyckeln ligger i tilläggets lokala lagring, inte i en server. Använd en separat, återkallningsbar nyckel — inte din huvudnyckel. Flikrubriker och domäner skickas till Anthropic vid gruppering.

Kräver Edge Canary eller Dev med flaggan Prompt API for on-device language model påslagen i edge://flags, samt tillräcklig hårdvara. Inget lämnar maskinen.

Dubbletter

Fästa flikar stängs aldrig. Senaste städningen går alltid att ångra från paletten.

Inaktiva flikar

Inget stängs utan förhandsvisning (Ctrl+I i paletten). Fästa, aktiva och ljudspelande flikar föreslås aldrig.

Gruppering

Kortkommandon

Ctrl+Shift+K öppnar paletten, Ctrl+Shift+U städar dubbletter. Grupperingskommandot saknar standardtangent.
